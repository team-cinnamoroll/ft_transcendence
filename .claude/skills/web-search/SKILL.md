# 🛠️ Skill Details

このスキルは、Web検索時のルールを定め、効率的かつ効果的な情報収集を目的としています。適切な検索手法は、開発作業の効率を高め、問題解決の速度を向上させます。

## Web検索のルール

- **言語**: 検索クエリはすべて日本語で入力してください。
- **キーワードの選択**: 検索結果が関連性の高いものになるように、具体的で適切なキーワードを選択してください。
- **検索の信頼レベル**: 下記の1~3の順序で、信頼性の高い情報からトップダウンで検索してください。
  1. 公式ドキュメントなどの信頼性の高い**一次情報**を参照してください。
  2. 1で有力な情報を取得できなかった場合は、次に信頼性の高い**二次情報**を参照してください。
  3. 2で有力な情報を取得できなかった場合は、次にブログ記事やフォーラムなどの**三次情報**を参照してください。
- **検索結果の評価**: 検索結果を慎重に評価し、信頼性の高い情報を優先的に活用してください。
- **結果の出力**: 検索結果は、情報源のURL、情報源の信頼レベル、検索結果の要約を出力してください。
- **情報の整理**: 取得した情報を整理し、必要に応じてメモや要約を作成してください。
