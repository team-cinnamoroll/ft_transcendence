# MultiFace 新構想 UI/UX仕様（PC比率）

## このドキュメントの目的

本ドキュメントは、MultiFace 新構想の PC比率 UI/UX を定義する。
ただし、現在接続中の Figma には PC比率の画面が存在しないため、本ドキュメントでは未確定情報を持たず、確定済み事項だけを記載する。

共通方針は [docs/frontend-bff/NEW_CONCEPT_UI_UX.md](docs/frontend-bff/NEW_CONCEPT_UI_UX.md) を参照する。

---

## 1. 現在確定していること

- UIデザインの正本は Figma とする
- 現時点で確認できる画面はスマホ比率のみである
- PC比率の個別レイアウト、導線、AC は未確定である

---

## 2. このドキュメントで扱わないこと

- 2 カラム / 3 ペインなどの具体レイアウト
- フェイス管理の表示方式
- 検索、再発見、週次レビューの PC向けUI
- 表示密度やキーボード操作の詳細ルール

---

## 3. 更新ルール

- PC比率の画面が Figma に追加・確定した時点で、このドキュメントへ反映する
- それまでは [docs/frontend-bff/NEW_CONCEPT_UI_UX.md](docs/frontend-bff/NEW_CONCEPT_UI_UX.md) と [docs/frontend-bff/NEW_CONCEPT_UI_UX_MOBILE.md](docs/frontend-bff/NEW_CONCEPT_UI_UX_MOBILE.md) を参照する
